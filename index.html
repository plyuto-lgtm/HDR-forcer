Files are processed locally — nothing is uploaded. Three modes: Assign keeps pixel values and tags Rec.2020 + PQ — max glow, survives LinkedIn's re-encode, best in Chrome. Convert remaps sRGB → Rec.2020 PQ first for cleaner color. Gain map packs an SDR base + a boost map (UltraHDR) — the format iOS Photos & Safari render, but it can be stripped by aggressive re-encoders like LinkedIn's avatar pipeline. Combined (experimental) puts a PQ base and a gain map in one file — aiming to glow everywhere at once. Test it on your devices.
